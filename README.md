# 🛒 KARTLANE – E-Commerce Multi-Filter Application

**KARTLANE** is a modern, responsive e-commerce product browsing platform designed to make product discovery faster, smarter, and more convenient.

Explore a wide range of products with powerful filtering options, including categories, price ranges, and customer ratings. Experience seamless browsing with instant filtering, dynamic search, and smart sorting — all through a clean and intuitive interface.

## ✨ Features

- **Multi-Category Filtering:** Select multiple product categories simultaneously.
- **Dual-Range Price Slider:** Filter products by minimum and maximum price.
- **Star Rating Filter:** Find products based on minimum customer ratings.
- **Instant Filtering:** Product listings update automatically whenever filters change.
- **Smart Sorting:** Sort products by price (Low to High / High to Low) and highest ratings.
- **Product Search:** Search products by name.
- **Dynamic Product Count:** View matching products instantly.
- **Add to Cart:** Add products and track the cart count.
- **Reset Filters:** Restore default filter settings with one click.
- **Empty State Handling:** Display a helpful message when no products match.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

## 🛠️ Tech Stack

- JavaScript

## ⚙️ Core Functionality

KARTLANE implements a combinatorial multi-filtering system that processes multiple filtering conditions simultaneously.

- Category matching
- Minimum and maximum price validation
- Minimum star rating validation
- Product name search
- Dynamic sorting after filtering

All filtering operations work together to provide accurate and instant product results.

## 🎯 Project Objective

To develop a modern and scalable e-commerce browsing experience that demonstrates efficient state management, reusable components, dynamic filtering, sorting algorithms, and responsive UI development.
